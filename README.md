# Afondamento

Este repositorio reúne una colección de programas desarrollados en Java sobre conceptos fundamentales de álgebra matricial.

## 📁 Contenido

El código (`src/`) se encuentra organizado por:

- **Operaciones Aritméticas:**
  - Suma y resta de matrices.
  - Producto de matrices.
- **Propiedades y Análisis de Matrices:**
  - Matriz traspuesta.
  - Cálculo de la traza.
  - Comprobación de simetría.
  - Verificación de matriz diagonal.
